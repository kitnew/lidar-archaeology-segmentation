\chapter{Results and Discussion}\label{ch:results_discussion}

\section{Overview of Conducted Experiments}

This chapter presents the quantitative and qualitative results of the conducted experiments. The experiments were treated not as an independent sequence of model runs, but as a set of controlled experimental groups. Each group was designed to assess the impact of a single methodological component, such as input data representation, label representation, loss function, sampling strategy, or model architecture. This structure allows us to distinguish general trends from the specific results of individual configurations. A detailed description of all configurations will not be provided due to their high variability; they follow directly from the methodology described above and adhere to a defined evaluation protocol.

Experiments were conducted separately for the datasets on Maya structures and Slovak terraces, as these two study areas differ in object morphology, terrain context, and annotation characteristics. The Maya dataset focuses primarily on compact archaeological structures, whereas the Slovak dataset contains linear objects similar to terraces. Therefore, the results are presented separately for both areas and only then compared at the level of methodological trends. A complete description of the characteristics of the available data is provided in Chapter 4.

Only experiments conducted on the latest consistent version of the workflow will be considered to ensure the objectivity of the subsequent comparison and to minimize the impact of possible methodological drift from minor changes. This will ensure a meaningful comparison of the tested components regardless of the input data domain.

\section{Reference and Best-Performing Configurations}
\subsection{Best-Performing Configuration for Maya Structures}

For the Maya dataset, the best-performing configuration was obtained with the following setup:
\begin{itemize}
    \item Model: DeepLab V3+ with an ImageNet-pretrained ResNet-101 backbone;
    \item Input representation: SPS visualization with radius = 10 m, n\_dir = 16, noise\_sup = 0, and z-score normalization;
    \item Label representation: soft mask with radius = 2 m;
    \item Loss function: Tanimoto with complement loss;
    \item Tile size: $128 \times 128$ pixels with a stride of 32 pixels.
\end{itemize}

This configuration is used as the reference result for the Maya structures because it achieved the strongest overall performance among the evaluated variants. To provide a meaningful comparison, it is contrasted with the older DeepLab V3 model trained without pretrained weights. This comparison should not be interpreted as an isolated evaluation of pretraining alone, since the models also differ architecturally. However, it remains useful as a representative comparison between the strongest final configuration and the earlier baseline, especially because the non-pretrained DeepLab V3 and DeepLab V3+ variants showed only minor differences in the preliminary experiments.

The pixel-wise results are summarized in Table~\ref{tab:maya_v3_v3plus_metrics}. Only the metrics that provide useful information for this highly imbalanced segmentation problem are reported. Overall accuracy and background-dominated measures were omitted, since they can overestimate performance when the foreground class occupies only a small part of the raster. The results show that the DeepLab V3+ configuration improves all retained pixel-level indicators. The most important improvements are visible in foreground IoU, F1 score, and Matthews correlation coefficient, which indicates that the model provides a more balanced segmentation of the archaeological structures rather than merely preserving the dominant background class.

\subsection{Best-Performing Configuration for Slovak Terraces}

For the Slovak terrace dataset, the best-performing configuration was obtained with the following setup:
\begin{itemize}
    \item Model: DeepLab V3+ with a ResNet-101 backbone;
    \item Input representation: ANISO visualization;
    \item Label representation: soft mask with radius = 2 m;
    \item Loss function: BCE+Dice loss;
    \item Tile size: $512 \times 512$ pixels with a stride of 128 pixels.
\end{itemize}

This configuration is used as the reference result for the Slovak terrace dataset because it achieved the strongest overall performance among the evaluated variants. However, in contrast to the Maya structures, the interpretation of the Slovak results is less straightforward. The terrace task involves narrow, elongated, and partially discontinuous features represented by buffered polylines. Therefore, a prediction may correctly indicate the presence of a terrace complex while still obtaining relatively low pixel-wise overlap with the reference mask.

To keep the comparison consistent with the Maya results, the selected DeepLab V3+ configuration is compared with the same architecture using an ImageNet-pretrained backbone. The comparison shows a clear difference between the two variants. Although the pretrained model showed more stable behaviour during training, the final validation metrics favour the model trained from scratch. As shown in Table~\ref{tab:slovakia_v3_v3plus_metrics}, the non-pretrained DeepLab V3+ achieved higher balanced accuracy, true positive rate, F1 score, foreground IoU, average IoU, and Matthews correlation coefficient. The only retained pixel-level metric in which the pretrained model performed better is positive predictive value, indicating a more conservative prediction behaviour.

\section{Ablation Study}

The purpose of the ablation study is to evaluate the influence of individual methodological components on the final segmentation performance. Each experiment group isolates one controlled variable, while the remaining components are kept identical within that group. Therefore, the comparisons below should be interpreted only inside the corresponding group: input representation is compared with fixed training settings, label representation is compared within paired configurations, tile size is compared with the same model and loss setup, and so forth. This makes it possible to attribute the observed differences to the tested component rather than to unrelated changes in the pipeline.

\subsection{Effect of Input Representation}

The first ablation group evaluates the effect of LiDAR-derived input representation. Four representations were compared on the Maya dataset: DEM, RGB, RGDEM, and SPS. All variants were evaluated using the same model architecture, label representation, loss function, tile configuration, training procedure, validation split, and threshold optimization strategy. Therefore, the input representation is the only controlled component in this comparison.

The results are shown in Table~\ref{tab:maya_input_metrics}. Among the tested representations, SPS achieved the strongest performance across all reported metrics. The foreground IoU increased to 0.43, compared with 0.37 for RGDEM, 0.36 for RGB, and 0.25 for DEM. The same trend is visible in precision, recall, and F1 score. This indicates that the combination of slope, positive openness, and sky-view factor provides more informative local terrain contrast than the direct DEM representation or RGB-like visualization alone.

The DEM representation produced the weakest result. RGDEM and RGB performed similarly, with RGDEM achieving slightly better foreground IoU and F1 score. However, the improvement remains smaller than the difference between SPS and the other input variants.

\subsection{Effect of Label Representation}

The second ablation group evaluates the effect of label representation. Hard binary masks are compared with soft masks based on the same input representation. In this table, the relevant comparison is therefore not between all columns globally, but between each original representation and its corresponding soft-mask variant. All other components, including model architecture, input representation, loss function, tile size, and validation protocol, are kept unchanged inside each pair.

The results are summarized in Table~\ref{tab:maya_label_metrics}. The effect of soft labels is not uniform. For SPS and RGB, soft masks slightly improved foreground IoU and F1 score. For RGDEM, the soft-mask variant produced a minor decrease in foreground IoU and F1 score. For DEM, the difference is negligible. This indicates that soft boundary supervision does not automatically improve segmentation quality in all cases.

\section{Error Analysis}

The error analysis was conducted to identify the main failure modes of the trained segmentation models and to relate them to the properties of archaeological LiDAR data. The analysis is based on qualitative inspection of selected prediction maps in a GIS environment. The examples distinguish between false positives, false negatives, true positives, and boundary-related errors. This qualitative step is necessary because pixel-wise metrics alone do not fully explain whether a prediction is archaeologically meaningful or merely numerically correct.

The observed errors can be divided into three main categories: false-positive predictions, false-negative predictions, and boundary errors. These categories are closely related to the morphology of archaeological objects, the visual similarity between anthropogenic and natural terrain forms, and the uncertainty of expert annotations.

False-positive predictions occur when the model identifies terrain forms as archaeological structures even though they are not included in the reference annotation. An example is shown in Figure~\ref{fig:maya_fp_example_1}. The predicted regions are located on local relief anomalies that visually resemble archaeological remains. These forms include curved, rectangular, or edge-like terrain patterns with strong local contrast. From the model perspective, such areas are difficult to distinguish from actual structures because they contain similar geometric and topographic cues. Therefore, false positives are not random noise, but usually appear in places where the terrain morphology is similar to the learned archaeological class.

\begin{figure}[H]
    \centering
    \includegraphics[width=0.75\textwidth]{figures/maya_fp_example_1.pdf}
    \caption{Example of false-positive predictions on the Maya dataset. The model activates on terrain forms that are not included in the reference annotation but visually resemble archaeological structures.}
    \label{fig:maya_fp_example_1}
\end{figure}

Several sources of false positives were identified. The first source is natural terrain morphology that resembles anthropogenic structures, especially small mounds, depressions, sharp slope transitions, or locally regular relief forms. The second source is modern disturbance, such as tracks, edges of modified terrain, or other recent landscape changes. The third source is the visualization itself: LiDAR-derived representations may enhance local contrast and create artefacts that appear structurally meaningful to the model. In addition, some predictions classified as false positives may represent unannotated or ambiguous candidates rather than clear model errors, since the available labels should not be interpreted as a perfect archaeological inventory.

False-negative errors occur when annotated archaeological objects are missed by the model. Figure~\ref{fig:maya_fn_example} shows that this problem is especially common for small, isolated, weakly preserved, or low-contrast structures. In many cases, the objects are visible in the reference annotation but only weakly expressed in the terrain visualization. Such objects provide limited visual evidence for the model and can easily be suppressed as background, particularly when they are surrounded by heterogeneous natural terrain.

The false-negative examples also show that the model performs better on larger or more coherent groups of structures than on individual small objects. In the lower part of Figure~\ref{fig:maya_fn_example}, several structures are partially detected, but the segmentation remains incomplete. This indicates that the model can recognize stronger archaeological morphology, but it often fails to recover the complete set of small neighbouring structures. For archaeological prospection, this is an important limitation because small structures form a substantial part of the reference dataset and may be relevant for settlement interpretation.

    \label{fig:maya_fn_example}
\end{figure}

Boundary errors represent a separate class of problems. They occur when the model detects the correct archaeological object or terrain feature, but its predicted extent does not match the reference mask. Figure~\ref{fig:maya_boundaries_error} illustrates a strong boundary mismatch. The model identifies only parts of the visible relief expression, while a large part of the annotated area remains classified as false negative. This suggests that the model follows the present-day terrain signal rather than the full idealized or expert-interpreted outline stored in the reference annotation.

\begin{figure}[H]
    \centering
    \includegraphics[width=0.75\textwidth]{figures/maya_boundaries_error.pdf}
    \caption{Example of a boundary error on the Maya dataset. The model detects only the most visible parts of the relief expression, while the larger annotated structure remains partly undetected.}
    \label{fig:maya_boundaries_error}
\end{figure}

This behaviour is expected in archaeological LiDAR segmentation. Expert annotations often represent interpreted archaeological objects rather than exact present-day relief boundaries. As a result, a structure may be annotated as a coherent polygon, while the visible terrain expression is fragmented, eroded, or shifted. The model, however, learns directly from raster appearance. It therefore tends to activate on the most visually expressed parts of the object, such as edges, mounds, walls, or slope transitions, instead of reproducing the full archaeological outline.

A contrasting example is shown in Figure~\ref{fig:maya_boundaries_success}. In this case, the model successfully identifies the main structure and produces a spatially coherent prediction. Nevertheless, small red and blue regions remain along the object boundary. This demonstrates that even successful predictions often contain minor boundary disagreement. Such errors may reduce pixel-wise metrics, although the result remains useful for expert inspection because the main archaeological object is correctly localized.

\begin{figure}[H]
    \centering
    \includegraphics[width=0.75\textwidth]{figures/maya_boundaries_success.pdf}
    \caption{Example of a successful boundary prediction on the Maya dataset. The main archaeological structure is correctly localized, although minor boundary disagreement remains visible along the object edges.}
    \label{fig:maya_boundaries_success}
\end{figure}

Soft masks partially address this problem by reducing the penalty for small boundary deviations. However, they do not eliminate the underlying mismatch between the raster-visible relief and the expert-defined archaeological outline. Moreover, softer supervision can encourage broader predictions and increase false positives. Therefore, boundary errors should be interpreted not only as model inaccuracies, but also as evidence of uncertainty in the relation between annotation geometry and terrain expression.

Overall, the error analysis shows that the model is more reliable at identifying distinct and morphologically clear archaeological structures than at precisely delineating all reference boundaries. The main practical limitation is not only the presence of false positives or false negatives, but the ambiguity of the target class itself. Archaeological structures are often eroded, partially preserved, visually similar to natural forms, and represented by annotations that may be schematic or conservative. For this reason, the model output should be treated as a candidate layer for expert-guided interpretation rather than as a final archaeological map.

\section{Archaeological Usefulness of the Results}

The obtained results should not be interpreted as a replacement for expert archaeological interpretation. The models developed in this thesis are more appropriate as decision-support tools that highlight candidate areas for further inspection. This interpretation is especially important in archaeological LiDAR analysis, where the main practical objective is often not the automatic production of a final archaeological inventory, but the reduction of the area that must be manually inspected by an expert.

From this perspective, false positives and false negatives do not have the same practical impact. A false-positive prediction increases the amount of material that must be reviewed, but it can often be rejected relatively quickly during expert inspection. A false negative is more problematic, because it represents a potentially missed archaeological feature. Therefore, in the context of exploratory prospection, a model with higher candidate coverage may still be useful even if it produces additional false-positive predictions.

For the Maya dataset, the model output is particularly useful for candidate structure detection. The object-level hit rates by size category are shown in Table~\ref{tab:maya_hit_rate_by_size}. It can help identify zones where terrace-like morphology is present, but the continuity of individual terrace segments, their archaeological interpretation, and the rejection of false positives require expert verification. In summary, the archaeological usefulness of the results depends strongly on the intended use case. For the Maya dataset, the model is useful as a candidate detector for medium and large structures, but it remains limited for small and weakly preserved features. For the Slovak terrace dataset, the model is useful for highlighting probable terrace zones, but not for automatically extracting complete and reliable terrace geometries. In both cases, the output should be treated as a supporting layer for expert-guided inspection rather than as a final archaeological interpretation.

\section{Limitations}

Several limitations must be considered when interpreting the results of this thesis. These limitations are related not only to the trained models themselves, but also to the available reference data, the morphology of the archaeological objects, the evaluation protocol, and the practical use of the predicted masks in a GIS environment.

The first limitation concerns the uncertainty of the reference data. The available annotations should not be interpreted as perfect ground truth. In the Maya dataset, the labels represent expert-interpreted archaeological structures and may include simplified or idealized boundaries. In the Slovak dataset, the terrace annotations are represented as buffered polylines rather than precise polygonal outlines of the actual relief expression. As a result, there may be a spatial mismatch between the visible terrain morphology and the reference mask used for training and evaluation. This limitation directly affects both model learning and quantitative metrics, because the model may detect a real terrain feature but still be penalized if the prediction does not coincide with the annotation geometry.

The second limitation is the strong class imbalance between archaeological features and background. In both datasets, the target class occupies only a small fraction of the raster area. This imbalance affects training, threshold selection, and metric interpretation. A model can achieve high background performance while still failing to detect a substantial part of the archaeological class. For this reason, overall accuracy and background-dominated measures are not sufficient for evaluating the results. Even foreground-oriented metrics such as IoU, precision, recall, and F1 score must be interpreted together with qualitative inspection.

The third limitation is the limited cross-domain generalization between the Maya and Slovak datasets. Although both datasets are based on airborne LiDAR-derived terrain data, they differ substantially in spatial resolution, object morphology, annotation type, and landscape context. The Maya dataset contains mostly compact polygonal structures, while the Slovak dataset contains narrow, elongated, and partially discontinuous terrace-like features. Therefore, a configuration that performs well on the Maya structures does not necessarily transfer directly to Slovak terraces. The results show that each domain requires its own adjustment of input representation, tile size, loss function, and interpretation strategy.

A related limitation is the difference in object morphology. Compact Maya structures are more compatible with standard semantic segmentation assumptions, because their spatial extent is relatively coherent and object boundaries are often easier to localize. In contrast, Slovak terraces are linear features with weak relief expression, fragmented continuity, and strong dependence on surrounding slope morphology. This makes them more difficult to segment as continuous binary masks. In many cases, the model identifies a broader terrace complex rather than individual terrace lines. Therefore, the Slovak results should be interpreted primarily as candidate localization, not as precise delineation.

Another limitation is that pixel-level metrics do not fully capture archaeological usefulness. A prediction can be slightly shifted from the reference mask and receive a low pixel-wise score, even though it correctly indicates a relevant archaeological candidate. Conversely, a prediction can overlap with the reference mask but still be fragmented or difficult to interpret archaeologically. This limitation is especially important for archaeological LiDAR data, where labels may be uncertain and the practical goal is often to support expert inspection rather than produce a final automatic map. For this reason, the quantitative evaluation was complemented by qualitative GIS-based assessment.

Full-area inference also remains dependent on expert interpretation. The generated probability maps and binary masks can reduce the amount of terrain that must be manually inspected, but they do not remove the need for archaeological expertise. False positives caused by natural relief forms, modern disturbances, visualization artefacts, or slope edges must still be reviewed manually. Similarly, false negatives may occur in weakly preserved, small, or low-contrast structures. The model output should therefore be treated as a decision-support layer rather than as an independent archaeological inventory.

The final limitation concerns the model and architecture design. This thesis evaluates selected DeepLab-based semantic segmentation models under a controlled experimental workflow, but it does not exhaustively test all possible architectures or parameter settings. Further improvement may require domain-specific adjustment of architectural parameters, such as input resolution, receptive field size, dilation rates, decoder design, or feature fusion strategy. If object detection or instance segmentation models are used in future work, additional parameters such as anchor sizes, feature pyramid settings, or instance-mask resolution may also need to be adapted to the physical scale and morphology of archaeological objects.

Overall, these limitations do not invalidate the obtained results, but they define the scope within which the results should be interpreted. The developed workflow demonstrates that deep learning can support archaeological LiDAR interpretation, especially by highlighting candidate areas. However, the results also show that reliable archaeological application requires careful data preparation, domain-specific validation, and expert-guided interpretation of model outputs.
